Feedmaker

Pega la URL de una web y consigue el enlace para añadirla a Feedly.

Marcada, el feed lleva el texto de cada artículo, y el repositorio público guarda una copia del texto de esa web. Sin marcar, solo título, enlace y extracto.

Conexión con GitHub (opcional)

Con un token, el botón lanza el workflow directamente. Sin token, se abre una incidencia en GitHub y hay que enviarla. El token se guarda solo en este navegador. Crea uno de acceso limitado a este repositorio, con permiso de Actions: lectura y escritura.

Si el propietario te ha dado una contraseña del servicio, pégala aquí: no necesitas token ni cuenta de GitHub.

Combinar varios feeds en uno

Marca de 2 a 5 feeds de «Mis feeds» y se creará un feed único con las entradas de todos, de la más reciente a la más antigua. Con filtro, solo pasan las entradas cuyo título, extracto o dirección contienen alguna de las palabras (completas: «caja» no coincide con «Cajasol»).
